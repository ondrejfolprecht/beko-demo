# Podklady současného webu

Snímek veřejné části BEKO Engineering z 4. 11. 2026.

Otevři `mapa-beko.html` pro mapu a diagram bez dalších nástrojů. `SPEC.md` popisuje dosavadní pravidla. `UX-AUDIT.md` popisuje doporučení. `routes.json` a `forms.json` poskytují inventář pro implementaci.

Nový rozsah 25 stránek, fázování a výchozí vizuální směr jsou v nadřazené složce v `docs/SCOPE.md`, `docs/DESIGN.md` a `docs/PAGES.md`. Původní údaje zachovávají stav průchodu. U nezjištěných backendových funkcí používá nová ukázka místní simulaci.

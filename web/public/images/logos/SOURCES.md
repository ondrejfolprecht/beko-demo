# Zdroje log

Stažené 6. 11. 2026 pro interní demo. Loga jsou ochranné známky svých vlastníků. Před zveřejněním musí BEKO potvrdit vztah s firmou a oprávnění logo použít. Barvu sjednocuje CSS.

- BMW, Volkswagen, Audi, Škoda, Ford: [Simple Icons](https://simpleicons.org/), u Audi a Fordu oříznutý viewBox
- Porsche, MAHLE, GRAMMER, Philips, Dassault Systèmes: [Wikimedia Commons](https://commons.wikimedia.org/), u GRAMMER a Philips doplněný viewBox
